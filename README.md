# Идеи — голосовой блокнот

Наговорите идею — текст сохранится. Нажмите «Копировать» и вставьте куда нужно.

Приложение работает в браузере Chrome на телефоне и компьютере.

## Тихий режим

По умолчанию приложение записывает звук и распознаёт его **без звуковых
сигналов Chrome**. Для этого используется модель GigaAM v3 (CTC, E2E),
которая работает прямо в браузере:

- первый раз скачивается около 230 МБ (один раз);
- модель сохраняется в памяти браузера (Cache API) и потом работает
  без интернета;
- текст появляется после нажатия «Стоп», а не по ходу речи;
- распознавание идёт в фоновом Worker, поэтому кнопки не зависают.

Обычный режим (распознавание Chrome по ходу речи, но с системным писком)
можно включить в меню «Ещё» → «Тихий режим».

## Быстрый режим с компьютером

Если рядом включён домашний компьютер, приложение сначала отправляет
запись на него. Там её распознаёт faster-whisper на видеокарте NVIDIA —
обычно в 7–10 раз быстрее реального времени. Связь идёт через приватную
сеть Tailscale и только между вашими устройствами; аудио никуда в
интернет не публикуется.

Если компьютер выключен или недоступен, приложение автоматически
переходит на обычное распознавание в браузере. Запись при этом не
теряется.

Настройка компьютера описана в `говорить/server/ИНСТРУКЦИЯ.txt`.
Адрес компьютера можно задать вручную в меню «Ещё» → «Компьютер» или
открыть приложение по ссылке с параметром `?server=https://…` — тогда
адрес сохранится сам.

## Устройство

- `app.js` — интерфейс, записи, переключение режимов.
- `asr-worker.js` — собранный Worker с onnx-asr-web и onnxruntime-web.
  Исходник: `tools/asr-worker-src.js`, инструкция: `tools/BUILD-ASR-WORKER.md`.
- `vendor/ort/` — WASM-движок ONNX Runtime (около 15 МБ).
- `models/` — небольшие служебные файлы моделей; большая модель
  скачивается с Hugging Face при первом запуске.
- `sw.js` — офлайн-оболочка и кэш модели распознавания.

Подробности о моделях и лицензиях — в `models/README.txt`.
